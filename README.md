# やさしいタスク

「今日やること」が一目で分かり、習慣・課題・進捗をカード形式でやさしく管理するiPhone向けアプリです。

## 現在の開発段階

フェーズ5：完了（品質確認・アクセシビリティ改善）

SwiftDataモデル、主要MVP画面、JSONバックアップ・復元、基本設定、入力・保存・起動時のエラー処理まで作成しています。

## 開発環境

- macOS Tahoe 26.5.2
- Xcode 26.6
- Swift
- SwiftUI
- SwiftData
- 対象：iPhone

## プロジェクトを開く方法

1. Macで `YasashiiTask/YasashiiTask.xcodeproj` を開きます。
2. Xcode上部でiPhoneシミュレーターを選びます。
3. 実行ボタン（▶）を押します。

## 基本フォルダ

- `App`：アプリ全体の起動と共通設定
- `Models`：保存するデータ
- `Views`：画面と共通表示部品
- `ViewModels`：画面の状態と処理
- `Services`：保存、バックアップ、検索などの共通処理
- `Navigation`：画面移動
- `Utilities`：共通の補助機能
- `Extensions`：既存機能の拡張
- `Resources`：色、画像、表示文字など
- `PreviewContent`：Xcodeプレビュー用データ

## 実装済みのMVP機能

- 習慣の一覧・作成・編集・削除
- 習慣に属するカードの作成・編集・完了
- 今日の習慣とカード、達成率の表示
- タイムラインとカレンダー
- 進捗・振り返り
- JSONバックアップ・復元
- ライト・ダーク・端末連動テーマ
- 完了時の振動設定
- 入力、保存、起動時のエラー表示

## 品質確認

- Xcodeでのビルドとシミュレーター起動を確認済み
